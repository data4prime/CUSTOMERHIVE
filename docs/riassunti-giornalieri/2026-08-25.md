# 2026-08-25 — Docker e CI

- Dockerizzato da zero l'ambiente di sviluppo locale (rimossi vecchi
  tentativi Docker), poi risolto un problema di performance passando
  `vendor/`, `storage/framework/` e `bootstrap/cache/` da bind mount a
  volumi Docker nominati.
- Completato un primo deploy locale funzionante su Docker.
- Analizzato e documentato il funzionamento di login e licensing esistenti
  (`docs/login-e-licensing.md`), e risolto il bug "Some parameters are
  missing" su `/admin/register-license`.
- Disattivati temporaneamente i controlli di licenza per poter lavorare in
  locale senza una licenza valida (marcatura `LICENSE-CHECK-DISABLED-DEV`),
  con checklist di cosa ripristinare prima del push (`docs/pre-push-checklist.md`).
- Definito il piano di modernizzazione/refactoring del progetto (upgrade
  Laravel, architettura, stabilità, setup, UI/UX), con lo schema di
  tracciamento in `docs/refactoring/`.
- Impostata la parte CI della pipeline: chiave SSH dedicata al deploy,
  GitHub Secrets, workflow GitHub Actions con job `tests` (prima un no-op,
  sistemato per eseguire davvero la suite PHPUnit con un service MySQL
  dedicato).
