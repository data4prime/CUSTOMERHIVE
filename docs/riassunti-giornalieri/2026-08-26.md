# 2026-08-26 — CD, refactoring auth e licensing

- Completata la pipeline CI/CD: job `deploy-dev` (deploy automatico via SSH
  su push a `dev`, con smoke test post-deploy), schema di permessi
  file Laravel+Apache sul server, e documentazione completa della pipeline
  (`docs/cicd-*.md`, `docs/permessi-dev-server.md`).
- Valutato il rischio di refactorare l'auth su un progetto in produzione e
  scelta una strategia additiva ("strangler fig"): guard Laravel nativo in
  parallelo al meccanismo a sessione custom di CRUDBooster, migrando i
  punti di lettura uno alla volta. Fatte Fase 0 (ricognizione) e Fase 1
  (guard additivo su `postLogin()`); in Fase 3, migrato `CBBackend` al
  guard `Auth::guest()` (con fix di `Auth::logout()` mancante).
- Scoperto e risolto un bug serio in `docker-compose.yml`: variabili DB
  forzate a livello di container bloccavano l'override di `.env.testing`,
  causando lo svuotamento ripetuto del database di sviluppo ad ogni run
  dei test locali.
- Approfondito il meccanismo di licensing e resi configurabili via `.env`
  `LICENSE_SERVER_URL` e `APP_DOMAIN`. Implementate le 3 migliorie
  concordate: controllo preventivo che l'ambiente sia configurato prima di
  attivare una licenza, riscrittura sicura di `registerLicense()` (client
  HTTP di Laravel invece di cURL con SSL disattivato e timeout infinito),
  nuova opzione "ho già una licenza".
- Testando questi cambiamenti, trovati e corretti due bug preesistenti che
  li rendevano di fatto inutilizzabili: un `TypeError` non gestito in
  `ConnectorService::getLicenseFromFile()` su ogni prima attivazione, e un
  500 su risposte inattese del server di licenza in `postActivateLicense()`.
- Riattivati i 4 controlli di licenza (rimossi i bypass temporanei),
  aggiungendo i guard di sicurezza che mancavano su 3 di essi.
- Aggiornata la documentazione di conseguenza (`docs/login-e-licensing.md`,
  `docs/pre-push-checklist.md`, nuovo `docs/refactoring/003-licensing-hardening.md`).
- Identificato (non risolto, non è codice nostro) un bug lato server di
  licenza remoto che blocca il completamento del test end-to-end
  dell'attivazione.
